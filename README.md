## 🎯 О проекте

АгроЛогистика решает задачу оптимизации доставки сельскохозяйственной продукции:

- **Управление складом** — учёт продукции (культуры, запасы, сроки доставки)
- **Хозяйство** — информация о ферме и её координаты
- **Покупатели** — база покупателей с заказами
- **Транспорт** — управление автопарком
- **Маршрутизация** — автоматический расчёт оптимальных маршрутов доставки

## 🛠 Стек технологий

### Backend
- **Python 3.11+** — основной язык
- **FastAPI** — веб-фреймворк
- **SQLAlchemy** — ORM для работы с базой данных
- **SQLite** — встроенная файловая база данных (не требует отдельного сервера)

### Frontend
- **React 18** — UI библиотека
- **TypeScript** — типизация
- **Tailwind CSS** — стилизация
- **React Router** — роутинг
- **Vite** — сборщик

## 🚀 Как развернуть

**Нужны:** Python 3.11+, Node.js 18+ и интернет (OSRM считает дороги).

**Не нужны:** Postgres, Docker, pgAdmin — ничего дополнительного поднимать не нужно.

Два процесса должны крутиться одновременно: бэк на порту `:8000`, фронт на порту `:3000`.

### Шаг 1. Клонировать репозиторий и зайти в корень

```bash
git clone <repo-url>
cd hackaton
```

### Шаг 2. Backend — отдельный терминал

```bash
cd backend
python -m venv .venv
.venv\Scripts\activate          # Windows
# или
source .venv/bin/activate      # macOS/Linux
pip install -r requirements.txt
.venv\Scripts\python -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
# macOS/Linux:
# python -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

✅ **Готово,** если открывается `http://127.0.0.1:8000/health` → `{"status":"ok"}`

- Схема API: `http://127.0.0.1:8000/docs`
- Карта защиты: `http://127.0.0.1:8000/map/`

### Шаг 3. Фронт — второй терминал

```bash
cd frontend
copy .env.example .env          # Windows
# или
cp .env.example .env           # macOS/Linux
npm install
npm run dev
```

В `.env` **должно быть**:

```env
VITE_API_URL=http://127.0.0.1:8000
VITE_SOLVER_URL=http://127.0.0.1:8000
```

> ⚠️ Без этого фронт пойдёт на порт 8001 и будет пустой/белый экран с ошибками API.

### Шаг 4. Открыть приложение

```
http://localhost:3000/
```

- Склад / хозяйство / покупатели / машины — данные из БД
- «Рассчитать» на маршрутах бьёт в `POST /api/v1/plan`

## 💾 База данных

Отдельно ничего запускать не надо. Это не сервер Postgres, а файл SQLite.

### Параметры

- **Файл:** `backend/agro.db` (появляется сам, в git не лежит)
- **URL по умолчанию:** `sqlite:///./agro.db` — путь относительно папки, из которой запущен uvicorn, то есть `backend/`
- **Схема:** `farms`, `products`, `buyers`, `buyer_orders`, `vehicles`

### Инициализация

При старте FastAPI вызывает `init_db()`: создаёт таблицы, и если хозяйства ещё нет — заливает seed:

- Хозяйство: Обнинск
- 3 культуры: Клубника, Томаты, Огурцы
- 4 покупателя, заказы (12 шт.)
- 3 машины: Газель А, Газель Б, Рефрижератор

### Работа с данными

- Меняешь данные в UI — пишется в этот файл
- Перезапуск бэка файл не трёт
- Seed ещё раз не запустится, пока в таблице `farms` есть запись
- CRUD идёт через `/api/v1/farm|products|buyers|orders|vehicles`
- Решатель БД не читает: фронт собирает JSON и шлёт на `/plan`

### Сбросить демо

1. Остановить бэк
2. Удалить `backend/agro.db`
3. Запустить бэк снова — seed накатится заново

> `DATABASE_URL` с Postgres нужен только если сам его задашь (как в `docker-compose.yml`). Для хакатона это лишнее.

## 📡 API документация

### Базовый URL

```
http://localhost:8000/api/v1
```

Полная Swagger-документация: `http://127.0.0.1:8000/docs`

### Сущности

#### Хозяйство (Farm)
| Метод   | Endpoint       | Описание         |
|---------|----------------|------------------|
| GET     | /farm          | Получить хозяйство |
| POST    | /farm          | Создать хозяйство  |
| PUT     | /farm          | Обновить хозяйство |

#### Продукция (Products)
| Метод   | Endpoint            | Описание         |
|---------|---------------------|------------------|
| GET     | /products           | Список продукции |
| POST    | /products           | Добавить продукт |
| PUT     | /products/{id}      | Обновить продукт |
| DELETE  | /products/{id}      | Удалить продукт  |

#### Покупатели (Buyers)
| Метод   | Endpoint            | Описание         |
|---------|---------------------|------------------|
| GET     | /buyers             | Список покупателей |
| POST    | /buyers             | Добавить покупателя |
| PUT     | /buyers/{id}        | Обновить покупателя |
| DELETE  | /buyers/{id}        | Удалить покупателя |

#### Заказы (Orders)
| Метод   | Endpoint                       | Описание         |
|---------|--------------------------------|------------------|
| GET     | /orders                        | Список заказов   |
| POST    | /orders                        | Создать заказ    |
| PUT     | /orders/{product_id}/{buyer_id}| Обновить заказ   |
| DELETE  | /orders/{product_id}/{buyer_id}| Удалить заказ    |

#### Транспорт (Vehicles)
| Метод   | Endpoint               | Описание         |
|---------|------------------------|------------------|
| GET     | /vehicles              | Список транспорта |
| POST    | /vehicles              | Добавить транспорт |
| PUT     | /vehicles/{id}         | Обновить транспорт |
| DELETE  | /vehicles/{id}         | Удалить транспорт |

#### Планирование (Solver)
| Метод   | Endpoint    | Описание              |
|---------|-------------|-----------------------|
| POST    | /plan       | Расчёт оптимальных маршрутов |

### Пример запроса

```bash
# Получить список продуктов
curl http://localhost:8000/api/v1/products

# Добавить продукт
curl -X POST http://localhost:8000/api/v1/products \
  -H "Content-Type: application/json" \
  -d '{
    "id": "strawberry",
    "name": "Клубника",
    "stock_kg": 600,
    "max_delivery_hours": 6
  }'
```
