## 🎯 О проекте

АгроЛогистика решает задачу оптимизации доставки сельскохозяйственной продукции:

- **Управление складом** — учёт продукции (культуры, запасы, сроки доставки)
- **Хозяйство** — информация о ферме и её координаты
- **Покупатели** — база покупателей с заказами
- **Транспорт** — управление автопарком
- **Маршрутизация** — автоматический расчёт оптимальных маршрутов доставки

## 🛠 Стек технологий

### Backend
- **Python 3.11+** — основной язык
- **FastAPI** — веб-фреймворк
- **SQLAlchemy** — ORM для работы с базой данных
- **PostgreSQL** — основная база данных
- **Docker** — контейнеризация

### Frontend
- **React 18** — UI библиотека
- **TypeScript** — типизация
- **Tailwind CSS** — стилизация
- **React Router** — роутинг
- **Vite** — сборщик

## 🚀 Быстрый старт

### Требования

- Python 3.11+
- Node.js 18+
- PostgreSQL 14+
- Docker & Docker Compose (опционально)

### Установка

#### 1. Клонирование репозитория

```bash
git clone <repo-url>
cd hackaton
```

#### 2. Backend

```bash
cd backend

# Создание виртуального окружения
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate

# Установка зависимостей
pip install -r requirements.txt

# Настройка переменных окружения
cp .env.example .env
# Редактирование .env с вашими данными БД

# Запуск сервера разработки
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

Backend запустится на `http://localhost:8000`
API документация: `http://localhost:8000/docs`

#### 3. Frontend

```bash
cd frontend

# Установка зависимостей
npm install

# Запуск сервера разработки
npm run dev
```

Frontend запустится на `http://localhost:5173`

## 📡 API документация

### Базовый URL

```
http://localhost:8000/api/v1
```

### Сущности

#### Хозяйство (Farm)
| Метод   | Endpoint       | Описание         |
|---------|----------------|------------------|
| GET     | /farm          | Получить хозяйство |
| POST    | /farm          | Создать хозяйство  |
| PUT     | /farm          | Обновить хозяйство |

#### Продукция (Products)
| Метод   | Endpoint            | Описание         |
|---------|---------------------|------------------|
| GET     | /products           | Список продукции |
| POST    | /products           | Добавить продукт |
| PUT     | /products/{id}      | Обновить продукт |
| DELETE  | /products/{id}      | Удалить продукт  |

#### Покупатели (Buyers)
| Метод   | Endpoint            | Описание         |
|---------|---------------------|------------------|
| GET     | /buyers             | Список покупателей |
| POST    | /buyers             | Добавить покупателя |
| PUT     | /buyers/{id}        | Обновить покупателя |
| DELETE  | /buyers/{id}        | Удалить покупателя |

#### Заказы (Orders)
| Метод   | Endpoint                       | Описание         |
|---------|--------------------------------|------------------|
| GET     | /orders                        | Список заказов   |
| POST    | /orders                        | Создать заказ    |
| PUT     | /orders/{product_id}/{buyer_id}| Обновить заказ   |
| DELETE  | /orders/{product_id}/{buyer_id}| Удалить заказ    |

#### Транспорт (Vehicles)
| Метод   | Endpoint               | Описание         |
|---------|------------------------|------------------|
| GET     | /vehicles              | Список транспорта |
| POST    | /vehicles              | Добавить транспорт |
| PUT     | /vehicles/{id}         | Обновить транспорт |
| DELETE  | /vehicles/{id}         | Удалить транспорт |

#### Планирование (Solver)
| Метод   | Endpoint    | Описание              |
|---------|-------------|-----------------------|
| POST    | /plan       | Расчёт оптимальных маршрутов |

### Пример запроса

```bash
# Получить список продуктов
curl http://localhost:8000/api/v1/products

# Добавить продукт
curl -X POST http://localhost:8000/api/v1/products \
  -H "Content-Type: application/json" \
  -d '{
    "id": "strawberry",
    "name": "Клубника",
    "stock_kg": 600,
    "max_delivery_hours": 6
  }'
```
