# Фронтенд

Эта папка для второго разработчика. Здесь только то, что открывается в браузере.

Страница `index.html` рисует ответ `POST /api/v1/plan`. Она не считает дороги и не выбирает машины. Кнопка берёт сценарий `GET /api/v1/demo/fleet` (3 машины, 10 покупателей) и отправляет его на план. Линии — `trips[].geometry`, точки — хозяйство и покупатели. Цвет линии совпадает с цветом остановок этой машины. Серые точки — покупатели, которых план не взял.

Координаты везде долгота, широта.

Бэкенд должен быть запущен. Страницу можно открыть как `http://127.0.0.1:8000/map/` или файлом `index.html`.
