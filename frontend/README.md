# Фронтенд

Эта папка для второго разработчика. Здесь только то, что открывается в браузере.

Сейчас это страница карты `index.html`. Карта рисуется библиотекой OpenLayers. Она не считает расстояния и не строит план поставок. По кнопке она отправляет точки на бэкенд:

`POST http://127.0.0.1:8000/api/v1/route`

В ответе приходят километры, часы, топливо, порядок точек `waypoints`, линия маршрута `geometry` и перегоны `legs`. Продуктовый экран эту ручку не вызывает: форма шлёт координаты на `POST /api/v1/plan` и рисует `trips[].geometry`.

Координаты на странице записаны как долгота, широта. Так их ждёт и бэкенд, и карта.

Бэкенд должен быть уже запущен. Страницу можно открыть файлом `index.html`.
