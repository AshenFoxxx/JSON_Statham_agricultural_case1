# АгроЛогистика — Документация

Документация проекта АгроЛогистика — системы планирования поставок сельскохозяйственной продукции с оптимизацией маршрутов.

## О проекте {#o-proekte}

АгроЛогистика решает задачу оптимизации доставки продукции от фермы к покупателям:

- Склад — управление продукцией (культуры, запасы, сроки доставки)
- Хозяйство — информация о ферме и её координаты
- Покупатели — база покупателей с заказами
- Транспорт — управление автопарком
- Маршрутизация — расчёт оптимальных маршрутов по реальным дорогам через OSRM
- Оптимизация — максимизация прибыли (выручка минус стоимость топлива) через OR-Tools CP-SAT

## Стек технологий {#stek-tekhnologiy}

| Компонент | Технологии |
|-----------|-----------|
| Frontend | React 19, TypeScript, Tailwind CSS, Vite 6, OpenLayers |
| Backend | Python 3.11+, FastAPI, SQLAlchemy, SQLite, OR-Tools CP-SAT |
| Маршруты | OSRM (расстояние и время по дорогам) |

## Формат документации {#format-dokumentatsii}

Документация построена по фреймворку [Diataxis](https://diataxis.fr/):

| Раздел | Тип | Для кого |
|--------|-----|----------|
| Tutorials | Обучение | Новички — пошаговые уроки |
| How-To | Практические руководства | Те, кто хочет решить конкретную задачу |
| Reference | Справочник | Те, кто ищет точные данные (API, конфиги) |
| Explanation | Объяснения | Те, кто хочет понять "почему" и "как работает" |

## Запуск документации {#zapuskn-dokumentatsii}

### Docker (рекомендуется)

```bash
cd docs
docker build -t docs .
docker run -p 5001:5001 docs
```

### Без Docker

```bash
pip install -r requirements.txt
python server.py --debug
```

Откройте: `http://localhost:5001`

Подробности запуска через Docker см. в разделе [Запуск через Docker](/doc/tutorials/02-docker-quickstart).

## Параметры запуска {#parametry-zapuska}

```bash
python server.py --port 8080 --host 0.0.0.0
```

| Параметр | По умолчанию | Описание |
|----------|:------------:|----------|
| `--port` | `5001` | Порт сервера |
| `--host` | `127.0.0.1` | Адрес привязки |

## API сервера документации {#api-servera-dokumentatsii}

| Endpoint | Описание |
|----------|----------|
| `GET /` | Редирект на первую страницу |
| `GET /doc/<page>` | Рендер markdown-страницы |
| `GET /api/toc` | Структура TOC в JSON |

## Добавление страниц {#dobavlenie-stranits}

1. Создайте `.md` файл в соответствующей папке `content/`
2. Добавьте запись в `toc.yaml`
3. Перезапустите сервер

## Формат toc.yaml {#format-tocyaml}

```yaml
- title: Название раздела
  file: path/to/page.md
  children:
    - title: Подраздел
      file: path/to/subpage.md
```

## Навигация {#navigatsiya}

На каждой странице внизу есть ссылки на предыдущую и следующую страницы:

```markdown

```
