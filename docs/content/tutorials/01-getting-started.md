# Обучение: Первые шаги

> **Тип:** Tutorial (обучающее руководство)
> 
> Цель: заставить вас работать с проектом с нуля, шаг за шагом.

---

## Что вы узнаете

В этом руководстве вы:

1. Клонируете репозиторий
2. Запустите оба сервиса через Docker Compose
3. Построите свой первый маршрут
4. Откроете интерактивную карту в браузере

---

## Что вам понадобится

- **Docker Desktop** — [скачать](https://www.docker.com/products/docker-desktop/)
- **Git** — [скачать](https://git-scm.com/)
- Любой браузер

---

## Шаг 1. Клонирование репозитория

Откройте терминал и выполните:

```bash
git clone <url-репозитория>
cd Hackaton
```

---

## Шаг 2. Запуск сервисов

В корне проекта выполните:

```bash
docker compose up --build
```

Это запустит два сервиса:

| Сервис | Порт | Описание |
|--------|------|----------|
| `map` | — | CLI-инструмент для построения маршрутов |
| `docs` | `5001` | Веб-интерфейс документации |

Дождитесь сообщений:

```
map_1        | Готово!
docs_1       | * Running on http://0.0.0.0:5001
```

---

## Шаг 3. Построение маршрута

Сервис `map` — это CLI-инструмент. Запустите его из терминала:

```bash
docker compose run map \
  --from "55.7558,37.6173" \
  --to "59.9343,30.3351"
```

Это построит маршрут **Москва → Санкт-Петербург**.

Вы увидите вывод:

```
Маршрут: (37.6173, 55.7558) -> (30.3351, 59.9343)
Цена топлива: 62.0 руб/л
Расход топлива: 35.0 л/100км
Запрашиваю маршрут...

Результат:
  Расстояние: 708.42 км
  Время в пути: 8.4 ч
  Расход топлива: 247.95 л
  Стоимость топлива: 15372.90 руб

JSON сохранён: output/route.json
Геометрия сохранена: output/route_geometry.json
Карта сохранена: output/route_map.html

Готово!
```

---

## Шаг 4. Просмотр карты

Откройте файл `output/route_map.html` в браузере — вы увидите интерактивную карту с маршрутом.

Или запустите standalone-просмотрщик:

```bash
docker compose run map --output output
```

Затем откройте `output/frontend/index.html`.

---

## Шаг 5. Изучение документации

Откройте [http://localhost:5001](http://localhost:5001) — здесь доступна документация проекта.
