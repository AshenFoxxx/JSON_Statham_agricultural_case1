# Объяснение: Как работает расчёт маршрута

> **Тип:** Explanation (объяснение)
> 
> Цель: понять, как проект получает и обрабатывает данные маршрута.

---

## Контекст

Проект должен ответить на четыре вопроса:

1. **Какой путь** соединяет две точки?
2. **Насколько длинный** этот путь?
3. **Сколько времени** займёт поездка?
4. **Сколько топлива** нужно и сколько это стоит?

---

## Шаг 1. Запрос к OSRM

OSRM (Open Source Routing Machine) — open-source движок маршрутизации.

```
GET http://router.project-osrm.org/route/v1/driving/37.6173,55.7558;30.3351,59.9343?overview=simplified&geometries=geojson
```

**Что происходит:**

1. OSRM берёт карту дорог (на основе OpenStreetMap)
2. Строит граф дорог между точками
3. Находит оптимальный путь по алгоритму поиска (CH/MLD)
4. Возвращает геометрию, расстояние и время

**Почему OSRM:**

- Бесплатный и open-source
- Не требует API-ключа
- Работает на данных OpenStreetMap
- Можно запустить свой сервер для production

---

## Шаг 2. Обработка ответа

OSRM возвращает JSON:

```json
{
  "routes": [{
    "distance": 708420.5,
    "duration": 30240.3,
    "geometry": {
      "type": "LineString",
      "coordinates": [[37.6173, 55.7558], [...], [30.3351, 59.9343]]
    }
  }]
}
```

Проект преобразует это в удобный формат:

```python
distance_km = 708420.5 / 1000      # → 708.42 км
duration_hours = 30240.3 / 3600     # → 8.4 ч
```

---

## Шаг 3. Расчёт топлива

Формула линейная — пропорциональна расстоянию:

```
fuel_liters = (distance_km / 100) * consumption
fuel_cost   = fuel_liters * price
```

**Пример:**

```
distance = 708.42 км
consumption = 35 л/100км
price = 62 руб/л

fuel = (708.42 / 100) * 35 = 247.95 л
cost = 247.95 * 62 = 15,372.90 руб
```

**Почему так просто:**

- Нет учёта пробок, рельефа, погоды
- Нет учёта типа груза
- Для хакатона и прототипа — достаточно

---

## Шаг 4. Генерация карты

Данные маршрута встраиваются в HTML-шаблон:

```python
html = TEMPLATE.replace("DISTANCE_VAL", f"{distance_km:.0f}")
```

Затем генерируется JS-файл, который:

1. Инициализирует Leaflet-карту
2. Рисует маршрут как полилинию
3. Ставит маркеры старта и финиша
4. Автоподгоняет зум к маршруту

## Ограничения

### Что НЕ учитывается

- Пробки и дорожные работы
- Погодные условия
- Ограничения по весу/высоте для мостов
- Таможня и границы
- Топливные станции по маршруту

### Что можно улучшить

- Использовать `overview=full` для более точной геометрии
- Добавить учёт рельефа (Elevation API)
- Интегрировать с реальными данными о пробках
- Добавить мульти-точечные маршруты (via points)
