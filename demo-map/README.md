# Карта маршрутов

Отдельная страница с картой плана поставок. Читает хозяйство, культуры, заказы и машины из той же SQLite-базы, что и основной интерфейс, затем вызывает `POST /api/v1/plan`.

Адрес при запущенном API: [http://127.0.0.1:8000/map/](http://127.0.0.1:8000/map/).

При запуске через Docker страница также доступна как [http://localhost:3000/map/](http://localhost:3000/map/).
